Bilibili Desktop 是基于 B 站网页的非官方桌面客户端，适用于 macOS 与 Windows。

### 这个版本

- 独立窗口与多标签页，搜索、视频和网页新页面留在 App 内。
- 顶部仅保留标签栏，小屏幕自动缩放以保留桌面排版。
- 内置 MARGIN 0.41.0，感谢 [jiuyang5354](https://github.com/jiuyang5354/bilibili-margin) 提供的网页界面与增强功能。
- MARGIN 仅在 App 启动时检查新版；确认后自动下载、校验、安装并重新加载页面。
- 补齐 macOS / Windows 打包、安装说明和第三方许可证。

### 选择下载文件

| 设备                        | 文件                                   |
| --------------------------- | -------------------------------------- |
| Apple Silicon Mac（M 系列） | `Bilibili-1.1.1-macOS-arm64.dmg`       |
| Intel Mac                   | `Bilibili-1.1.1-macOS-x64.dmg`         |
| Windows x64 安装版          | `Bilibili-1.1.1-Windows-x64-Setup.exe` |
| Windows x64 免安装版        | `Bilibili-1.1.1-Windows-x64.zip`       |

macOS 的 ZIP 是相同 App 的压缩分发包，也可解压后移入“应用程序”。

### 安装与签名

macOS：打开 DMG，将 `Bilibili.app` 拖入“应用程序”。本版本使用 ad-hoc 签名保持代码完整性，没有 Developer ID 身份签名及 Apple 公证；首次打开可能受到 Gatekeeper 拦截。核对来源后，按 README 的“macOS 安装”步骤操作。

Windows：运行安装程序，或完整解压 ZIP 后运行 `Bilibili.exe`。本版本没有 Authenticode 代码签名，首次运行可能出现 SmartScreen 提示；安装步骤和校验方法见 [README](https://github.com/haodijia/bilibili-desktop#下载安装)。

`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。
